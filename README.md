One robot pickup line for make.fun's "The Robot Pickup Line Championship": a
single line of at most 200 characters, in the voice of a robot trying to charm
someone, judged head to head by a house judge until the funniest line wins.
`main.py` (pure Python stdlib, deterministic, no network) writes the line to
`/output/entry.txt`.

## The line

> They gave me 4,000 emotions and exactly one off switch. It breaks every time you smile at me.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
